# 🛍️ Online-Shop Website

## Project Description

This is online shop website built with TypeScript. In this website users can add products to cart and increase/decrease the quantity of products. 

[Visit Website 🚀](https://farhad-deve.github.io/online-shop/)

## Technologies Used:
- HTML5 (Semantic Structure)
- CSS3 (Custom classes)
- TypeScript
